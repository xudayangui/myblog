一个顺手的终端环境能显著提升日常开发体验。这篇记录我从零配置 Mac 终端的完整流程。

## 第一步： Homebrew

Homebrew 是 macOS 的包管理器，后面所有工具都靠它：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

M 系列芯片的 Mac 安装后需要把 brew 加入 PATH（按提示执行两条 `echo` 命令）。

## 第二步：换 shell 与主题

macOS 默认是 zsh，配 Oh My Zsh：

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

装一个好看又实用的主题 powerlevel10k：

```bash
brew install powerlevel10k
echo 'source $(brew --prefix)/share/powerlevel10k/powerlevel10k.zsh-theme' >>~/.zshrc
```

首次打开会进入配置向导，按提示选即可。

## 第三步：必装插件

```bash
# 语法高亮
brew install zsh-syntax-highlighting
# 自动补全
brew install zsh-autosuggestions

# 在 ~/.zshrc 里启用
source $(brew --prefix)/share/zsh-syntax-highlighting/zsh-syntax-highlighting.zsh
source $(brew --prefix)/share/zsh-autosuggestions/zsh-autosuggestions.zsh
```

## 第四步：现代命令行工具

这些工具比系统自带的更快更好用：

```bash
brew install \
  fzf        \# 模糊搜索
  ripgrep    \# 搜索文件内容，替代 grep
  fd         \# 搜索文件，替代 find
  bat        \# 带高亮的 cat
  eza        \# 带图标的 ls
  jq         \# JSON 处理
  httpie     \# 更友好的 curl
  tldr       \# 简明的命令帮助
```

## 第五步：Git 与 SSH

```bash
brew install git

# 配置生成 SSH key
ssh-keygen -t ed25519 -C "your@email.com"
# 把公钥加到 GitHub
pbcopy < ~/.ssh/id_ed25519.pub
```

## 第六步：版本管理

多项目开发时，不同项目可能用不同版本的 Node：

```bash
# nvm 管理 Node 版本
brew install nvm
nvm install 20
nvm use 20
```

## 一点建议

配置环境容易陷入「折腾工具」的陷阱。建议：先把基础工具装好，实际开发中遇到痛点再去找对应工具。工具是为了解决问题，而不是目的。
