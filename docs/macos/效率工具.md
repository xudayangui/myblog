用好 Mac 做开发，工具链能省下大量时间。这份清单是我用了多年、真正留下来的工具，按场景分类。

## 终端相关

**iTerm2 + zsh + Oh My Zsh** 是经典组合。iTerm2 的分屏、搜索、快捷键比系统终端强太多。配上一个好用的主题（如 powerlevel10k），提示符能显示 git 分支、当前环境等信息。

```bash
# 安装 Homebrew（macOS 包管理器，一切的前提）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 常用软件一行装完
brew install --cask iterm2 visual-studio-code raycast
```

## 窗口与效率

- **Raycast**：替代 Alfred 的启动器，搜索应用、文件、剪贴板历史，还能跑脚本和 AI 对话
- **Rectangle** / **Arc**：窗口分屏管理，快捷键把窗口贴到左右半屏
- **Bartender**：收纳菜单栏图标，保持桌面干净

## 开发工具

- **VS Code**：配好 ESLint、Prettier、GitLens 基本够用
- **OrbStack**：比 Docker Desktop 更轻更快的容器运行时，启动速度差距明显
- **TablePlus**：数据库客户端，支持 MySQL/PostgreSQL/Redis 等，界面现代
- **Postman** / **Bruno**：API 调试，Bruno 是后起之秀，配置文件可进 git

## 系统增强

```bash
# 让隐藏文件显示
defaults write com.apple.finder AppleShowAllFiles YES && killall Finder

# 截图保存到指定目录而不是桌面
defaults write com.apple.screencapture location ~/Pictures/Screenshots

# 加速键盘重复（写代码时光标移动更快）
defaults write NSGlobalDomain KeyRepeat -int 2
```

## 终端里的宝藏工具

```bash
brew install fzf ripgrep fd bat eza jq

# fzf：模糊搜索，配合 Ctrl+R 搜索历史命令
# rg：比 grep 快得多的搜索
# bat：带语法高亮的 cat
# eza：带图标和颜色的 ls
# jq：处理 JSON 的瑞士军刀
```

## 键盘党必配

- **Karabiner-Elements**：键盘映射，比如把 Caps Lock 改成 Ctrl/Esc
- 系统设置里把「按住 Shift 切换输入法」关掉，避免大小写切换的困扰

## 小结

工具不在多，在于顺手。建议一次只引入一两个新工具，用熟了再加。真正提升效率的往往不是某个神器，而是把高频操作变成肌肉记忆。
