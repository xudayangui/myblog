Vue3 用 `Proxy` 重写了响应式系统，相比 Vue2 的 `Object.defineProperty` 有了质的提升。理解原理，才能真正用好它。

## 为什么换成 Proxy

Vue2 的 `defineProperty` 有三个痛点：

1. 无法监听对象属性的新增和删除
2. 无法监听数组下标和长度变化
3. 需要深度遍历对象，初始化开销大

`Proxy` 直接代理整个对象，完美解决这些问题：

```javascript
const raw = { count: 0 }

const proxy = new Proxy(raw, {
  get(target, key) {
    console.log('读取', key)
    return Reflect.get(target, key)
  },
  set(target, key, value) {
    console.log('修改', key, value)
    return Reflect.set(target, key, value)
  },
  deleteProperty(target, key) {
    console.log('删除', key)
    return Reflect.deleteProperty(target, key)
  }
})

proxy.count++    // 读取 count / 修改 count 1
proxy.name = 'x' // 修改 name x（新增也能捕获）
delete proxy.name // 删除 name
```

## 响应式系统的三要素

Vue 的响应式围绕三个概念：

- **effect（副作用函数）**：依赖响应式数据的函数
- **track（依赖收集）**：读取数据时，把当前 effect 存起来
- **trigger（触发更新）**：数据变化时，重新执行依赖它的 effect

一个最小实现：

```javascript
let activeEffect = null
const targetMap = new WeakMap()

function effect(fn) {
  activeEffect = fn
  fn()  // 执行时触发 get，完成依赖收集
  activeEffect = null
}

function track(target, key) {
  if (!activeEffect) return
  let depsMap = targetMap.get(target)
  if (!depsMap) targetMap.set(target, (depsMap = new Map()))
  let deps = depsMap.get(key)
  if (!deps) depsMap.set(key, (deps = new Set()))
  deps.add(activeEffect)
}

function trigger(target, key) {
  const deps = targetMap.get(target)?.get(key)
  if (deps) deps.forEach(fn => fn())
}

function reactive(obj) {
  return new Proxy(obj, {
    get(target, key) {
      track(target, key)
      return Reflect.get(target, key)
    },
    set(target, key, value) {
      Reflect.set(target, key, value)
      trigger(target, key)
      return true
    }
  })
}
```

使用：

```javascript
const state = reactive({ count: 0 })
effect(() => {
  console.log('count:', state.count)  // state.count 变化会自动重新打印
})
state.count++  // count: 1
```

## 深层响应式

上面的实现只代理了第一层。Vue 在 `get` 里做惰性代理：

```javascript
get(target, key, receiver) {
  const res = Reflect.get(target, key, receiver)
  track(target, key)
  return typeof res === 'object' && res !== null ? reactive(res) : res
}
```

只有访问到某层对象时才代理它，避免了初始化的深度遍历。

## ref 的实现

`ref` 本质是一个有 `value` 属性的响应式对象：

```javascript
function ref(value) {
  return reactive({ value })
}
```

当然 Vue 源码里做了优化（用对象的 getter/setter 而非 Proxy），但核心思路一致。

## 小结

Vue3 响应式 = Proxy 拦截 + 依赖收集 + 触发更新。记住 `activeEffect` 这个「当前正在执行的副作用」的巧妙设计，整个系统就串起来了。
