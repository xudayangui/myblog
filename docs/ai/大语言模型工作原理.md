不用公式、不看论文，用工程师能理解的方式讲清楚大模型到底在干什么。理解这些，你才知道为什么 Prompt 要这么写、为什么会有幻觉、上下文窗口到底意味着什么。

## 一切从 Token 开始

模型不认识"字"，只认识数字。输入文本先经过分词器（Tokenizer）切成 token，每个 token 映射成一个整数 ID：

```
"我喜欢写代码" → ["我", "喜欢", "写", "代码"] → [1024, 3421, 892, 5678]
```

中文一个 token 大致对应 1~2 个字，英文一个 token 约等于 4 个字符或 0.75 个单词。这就是"上下文窗口按 token 算"的原因——GPT-4 的 128K 上下文不是说能放 128K 个汉字，而是 token。

**一个关键认知**：模型看到的是 token 序列，不是字符。所以"strawberry 里有几个 r"这种问题它会答错——它压根没逐字符看过这个词。

## Embedding：把 token 变成向量

每个 token ID 会查表得到一个高维向量（几干维），叫做 embedding。语义相近的词，向量也相近——"猫"和"狗"的距离比"猫"和"汽车"近。

这些向量一开始是随机的，训练过程就是在调整它们，让语义关系在向量空间里成立。

## Transformer：注意力机制

这是核心。Transformer 的 Self-Attention 让模型在处理每个 token 时，能"看到"序列里其他所有 token，并判断谁更重要。

一句话理解注意力：

> 处理"它"这个词时，模型会计算它和前文每个词的关联强度——如果前文是"猫坐在垫子上，因为它累了"，模型会给"猫"很高的注意力权重。

这就是模型理解上下文的方式。所谓"上下文窗口"，就是注意力能覆盖的范围——超出窗口的信息，模型就"看不见"了。

**多头注意力**（Multi-Head）是同时从多个角度做这个事情：一个头关注语法关系，一个头关注指代关系，一个头关注位置关系……加起来形成对文本的立体理解。

## 预测下一个 Token

大模型本质在做一件事：**根据前面的 token，预测下一个 token 的概率分布**。

```
"今天天气很" → "好"(0.35) "热"(0.20) "冷"(0.15) ...
```

采样策略决定怎么从概率分布里选：

- **temperature 低**（0~0.3）：倾向选高概率词，输出确定、保守，适合代码、事实问答
- **temperature 高**（0.7~1.2）：更随机、更有创造性，适合写作、头脑风暴
- **top_p**：只从累计概率达到 p 的候选里选，和 temperature 配合使用

理解了这个，你就知道为什么同一个 Prompt 每次结果不同——因为采样有随机性。想让结果稳定，就把 temperature 设低甚至设为 0。

## 训练：Pretrain + Align

**预训练（Pretrain）**：拿海量的文本（书籍、网页、代码）让模型做"预测下一个 token"的任务。这个过程教会模型语言规律和世界知识，得到的叫**基座模型**。基座模型会"续写"，但不会"对话"——你问它问题，它可能续写出更多问题。

**对齐（Alignment）**：用 SFT（监督微调）+ RLHF（人类反馈强化学习）让模型学会听指令、按人类偏好回答。ChatGPT 之所以好用，很大程度赢在这一步。

## 幻觉从哪来

模型没有"事实数据库"，它生成的是"统计上最可能的 token 序列"。当它不知道答案时，依然会按模式生成一个看起来合理的答案——这就是幻觉。

应对方法：

1. **RAG**：先检索真实资料，把资料放进上下文让模型基于它回答
2. **工具调用**：让模型调用计算器、数据库、搜索引擎，用确定的工具结果代替生成
3. **降低 temperature**：减少自由发挥
4. **要求引用来源**：让模型指出答案依据哪段材料

## 上下文工程

既然模型只看得见上下文窗口里的东西，那么"把什么放进去、怎么组织"就成了核心技能：

- 重要信息放在开头或结尾（中间容易被"忽略"，即 Lost in the Middle 现象）
- 用清晰的结构（标题、列表）分隔不同信息
- 剔除无关内容，避免稀释注意力

这就是大家说"Prompt 工程"的本质——不是念咒语，是在有限的注意力预算里做信息调度。

## 小结

用一句话总结大模型的工作流程：

> 文本 → token → embedding → Transformer 注意力计算 → 预测下一个 token 的概率 → 采样 → 重复

理解这条链路，很多"玄学"现象就有了物理解释：幻觉是概率生成的必然、上下文限制是注意力的物理边界、temperature 控制的是采样的随机性。剩下的 Prompt 技巧，都是在这条链路上的工程优化。
